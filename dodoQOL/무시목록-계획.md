# 플레이어 메모 (무제한 무시 목록) 마이그레이션 계획

> GlobalIgnoreList 애드온에서 핵심 기능(무제한 무시 목록)만 dodoQOL에 포팅.

---

## 파일 구조

```
dodoQOL
  99 Options.lua ← 설정코드, DB 기본값 (기존 파일 수정)
  99 ETC/
    PlayerMemo.lua ← 동작코드 + UI (신규)
```

TOC에 1줄 추가 (기존 ETC 섹션).

```toc
99 ETC/PlayerMemo.lua
```

---

## DB 키 설계 (`dodoDB.*`)

| 키 | 타입 | 기본값 | 설명 |
|---|---|---|---|
| `enablePlayerMemo` | bool | `true` | 마스터 토글 |
| `playerMemoList` | table | `{}` | `["이름-서버"] = { note, date }` |
| `playerMemoMigrated` | bool | `false` | GIL → dodo 마이그레이션 완료 플래그 |

## 99 Options.lua 수정

`QOL_DEFAULTS`에 추가:
```lua
enablePlayerMemo = true,
```

`dodoDB` 초기화 블록에 추가:
```lua
dodoDB.playerMemoList    = dodoDB.playerMemoList or {}
```

"편의기능" 섹션에 체크박스 추가:
```lua
dodo.RegisterOption("편의기능.플레이어 메모", function(category)
    dodo.UI:SettingsCheckbox(category, "enablePlayerMemo", "플레이어 메모 & 무시",
        "플레이어별 메모를 관리하고, 같은 파티 진입 시 알림을 표시합니다.",
        true, function(val)
            if dodoDB then dodoDB.enablePlayerMemo = val end
        end)
end, 205)
```

## PlayerMemo.lua

### 패턴
```lua
local dodo = _G.dodo
dodoDB = dodoDB or {}
-- ADDON_LOADED 체크: arg1 == "dodoQOL"
```

### 네임스페이스
```lua
dodo.PlayerMemo = {}
local PM = dodo.PlayerMemo
```

### 공개 API
- `PM.Add(name, note)` — DB 저장 + `C_FriendList.AddIgnore(name)` 시도 (캡 초과 시 DB만 저장)
- `PM.Remove(key)` — DB 삭제 + `C_FriendList.DelIgnore(name)` 시도
- `PM.IsIgnored(key)` → bool
- `PM.RefreshUI()` — UI 행 재렌더 (UI 섹션에서 구현체 주입)

### 이벤트

| 이벤트 | 처리 |
|---|---|
| `ADDON_LOADED` | DB init + GIL 마이그레이션 시도 |
| `PLAYER_LOGIN` | DB → WoW 동기화 (각 항목 `AddIgnore` 시도) |
| `IGNORELIST_UPDATE` | WoW 목록 → DB 단방향 동기화 (WoW에서 새로 추가한 것만 흡수, note = "") |
| `GROUP_ROSTER_UPDATE` | 파티원 ∩ playerMemoList → 팝업 |
| `PLAYER_ENTERING_WORLD` | 파티 재진입 시 체크 |

### GIL 마이그레이션

```lua
-- ADDON_LOADED 시점에 실행
local function migrate_from_gil()
    if dodoDB.playerMemoMigrated then return end
    if not GlobalIgnoreDB or not GlobalIgnoreDB.ignoreList then return end
    for i, name in ipairs(GlobalIgnoreDB.ignoreList) do
        if GlobalIgnoreDB.typeList[i] == "player" then
            local key = name  -- 이미 "이름-서버" 형식
            if not dodoDB.playerMemoList[key] then
                dodoDB.playerMemoList[key] = {
                    note = GlobalIgnoreDB.notes[i] or "",
                    date = GlobalIgnoreDB.dateList[i] or "",
                }
            end
        end
    end
    dodoDB.playerMemoMigrated = true
end
```

### 파티 경고 팝업

```lua
StaticPopupDialogs["DODO_PLAYER_MEMO_WARN"] = {
    text = "%s",
    button1 = "확인",
    timeout = 0,
    whileDead = true,
    hideOnEscape = true,
}
```

- `UnitName()` 결과 → `issecretvalue()` 검증 후에만 DB 키 비교
- 여러 명이면 한 팝업에 합쳐서 표시:
  ```
  메모된 플레이어가 파티에 있습니다:

  ■ 이름-서버
    메모: 내용
  ```
- 동일 그룹 구성 반복 트리거 방지: `last_warned_set` (집합 비교)

### 프레임 생성 & FriendsFrame 연동

```lua
local frame = dodo.UI:CreatePortraitPanel("dodo_PlayerMemoFrame", "플레이어 메모")
frame:SetSize(480, 400)
frame:SetPoint("TOPLEFT", FriendsFrame, "TOPRIGHT", 2, 0)
frame:Hide()

-- 친구창 열림/닫힘에 연동
hooksecurefunc(FriendsFrame, "Show", function()
    if dodoDB.enablePlayerMemo ~= false then frame:Show() end
end)
hooksecurefunc(FriendsFrame, "Hide", function()
    frame:Hide()
end)
```

```

├────────────────────────────────────────┤
│ 이름-서버          메모              [×]│
```

- 스크롤 프레임: `CreateFrame("ScrollFrame", nil, frame, "UIPanelScrollFrameTemplate")`
- 행 풀(pool) 방식: 최대 15개 재사용
- 각 행: 이름 FontString + 메모 FontString + [×] 삭제 버튼
- 메모 클릭 → 인라인 EditBox 전환 (Enter 확정 / Esc 취소)
- `PM.RefreshUI` 구현체를 여기서 정의 후 주입

## 주요 고려사항

1. **WoW 캡 초과 시**: `AddIgnore` 실패해도 DB는 저장 → 파티 경고는 정상 작동, 채팅 차단만 안됨 (허용 가능한 트레이드오프)
2. **secret value**: `UnitName()` 결과 `issecretvalue()` 검증 후에만 DB 키 비교
3. **`IGNORELIST_UPDATE` 흡수**: WoW에서 직접 무시한 것도 DB에 추가 (note = "")
4. **중복 팝업 방지**: `GROUP_ROSTER_UPDATE`는 잦게 발생 → 이전 경고와 동일 조합이면 스킵
5. **GIL 마이그레이션**: `GlobalIgnoreDB` 존재 시 player 타입만 변환, `playerMemoMigrated` 플래그로 1회만 실행
6. 코드 작성 후, wow-addon 에이전트 활용해서 인게임 성능 최적화 진행. 그 후, 2dodo와 2dodo-options 스킬 활용해서 코드작성 규칙에 맞게 만들었는지 확인 검토.
